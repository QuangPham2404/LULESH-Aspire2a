## Main findings

- CCE13 is the fastest valid compiler environment in the recorded comparison.
- CCE13 `-O3` is the fastest valid tested optimization level.
- CCE13 `-Ofast` is faster in the recorded run but invalid because
  `MaxRelDiff=-nan`.
- The MPI sweep is weak-scaling-style because `-s 30` is interpreted per MPI
  domain; it is not fixed-global-size strong scaling.
- Eight OpenMP threads is the fastest measured valid configuration, but Cray
  affinity/oversubscription warnings make this result provisional.
- Each configuration currently has only one runtime measurement, so stable
  repeatability has not been established.

## Current next direction
